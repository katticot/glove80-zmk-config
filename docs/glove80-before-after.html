What else moved

Layers24 → 18. Function, Emoji, Symbol, Mouse, World and Lower are gone; Cursor was removed and restored.
Number layernow sends real KP_* keypad codes instead of the number row, because USE_NUMPAD_KEYCODES is defined. This is what replaced Lower's keypad.
Combosthe eight sticky-shift / hyper / meh / caps-word / tab-switcher combos fire on layers 0–11 instead of 0–8, so they now work while holding right ring2, middle or index.
World & Emojithe whole macro tree behind them is deleted: ~287 KB of source and 117 KB of firmware that nothing could reach.
&lowerbase #52 and Factory #54 no longer reach a Lower layer. Tap does nothing, double-tap returns to the base layer, which on Factory is the only way home.
Dead code58 unreachable behaviour nodes, 70 unused POS_* defines, the dead #ifndef OPERATING_SYSTEM fallback and unused editor scaffolding are deleted.
How this page is built

tools/make_before_after.py reads both revisions of the keymap, labels them with the Field Guide generator, and writes this page. Regenerate it after any keymap change:

uv run tools/make_before_after.py --before 856a4ff
